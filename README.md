# PulseDroid — updates

Public update feed and release downloads for **PulseDroid**, the USB movie
player that runs as the home screen on kiosk tablets. This repo contains only
`latest.json` (the self-update feed the app polls) and signed APKs on
[Releases](../../releases).

Direct download (always the newest version):
https://github.com/ijasonwhite/pulsedroid-updates/releases/latest/download/PulseDroid.apk

Tablets check `latest.json` on launch and every 6 hours and install newer
builds silently.
